## 提交约定

采用 Conventional Commits，并保持一个提交对应一个可验证功能：

- `docs:` 产品和运维文档
- `feat:` 新增可用功能
- `fix:` 修复已存在功能
- `test:` 增加测试或质量门禁
- `chore:` 构建、部署和非产品行为调整
